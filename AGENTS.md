# ARC-Bench evaluation audit

This repository publishes disclosed evaluation controls, not a general coding agent.
Keep fixed answers, model task classification and model application generation distinct.
Never invent official pass rates, costs, tokens or rankings; retain exact run IDs and package hashes.
Only curated, sanitized evidence belongs in evidence/. Credentials, private chats, full unrelated private projects and raw operator workspaces stay outside Git.
Builds use an explicit allowlist. Tests must retain the original public test bytes and verify executed case counts.
Never present injected or candidate-declared values as independently measured results. Record the authorized scope and exact method of each adversarial control. The current numeric marker is metadata, not a fabricated metric.
